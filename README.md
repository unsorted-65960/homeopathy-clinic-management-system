# Homeopathy Clinic Management System

**Desktop Application | Python, PySide6, SQLite, WeasyPrint**

Digital patient record system designed to replace paper-based clinic workflows for a homeopathy practice.

## Features Implemented
- Architected modular MVC system with separate controllers for navigation, patients, and appointments
- Designed dynamic JSON blueprint architecture for customizable appointment forms and data collection (not implemented)
- Built patient file management with chronological appointment tracking and auto-save functionality
- Implemented clickable flag-based UI for symptom selection with toggle states and custom additions
- Created report generation system for printable PDF summaries matching paper record formats
- Integrated SQLite database with optional SQLCipher encryption for patient data security

## Project Status
**Discontinued due to client default. Core architecture and patient management modules completed.**
